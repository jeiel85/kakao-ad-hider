작동 원리

호출 세 번이면 됩니다

광고는 메인 창이 소유한 팝업이고, 그 아래에는 광고만큼 비워 둔 빈 창이 있습니다. 둘을 숨기고 목록 창의 높이만 바꾸면 나머지는 카카오톡이 알아서 다시 그립니다.

  1. 광고 팝업 숨기기

    ShowWindowAsync(popup, SW_HIDE)

    메인 창이 소유하고, 빈 슬롯과 좌표가 같은 제목 없는 창만 고릅니다. 메뉴나 이모티콘 창은 건드리지 않습니다.

  2. 빈 슬롯 숨기기

    ShowWindowAsync(slot, SW_HIDE)

    광고가 놓이던 100px짜리 자리입니다.

  3. 목록 늘리기

    SetWindowPos(view, …, 796)

    바깥 목록 창 크기만 바꾸면 안쪽 목록과 왼쪽 메뉴는 카카오톡이 다시 배치합니다.

창 크기를 바꾸면 카카오톡이 목록을 다시 광고 자리 위까지 줄입니다. 그래서 kakao-ad-hider는 카카오톡의 창 표시·크기 변경 이벤트를 듣고 있다가 다시 적용합니다. 개발 PC에서 재어 보니 약 40ms 안에 끝났습니다.

범위

바꾸는 건 창의 표시와 크기뿐

하는 일

  • 목록 아래 광고 팝업과 빈 슬롯을 숨깁니다
  • 친구·채팅 목록을 창 바닥까지 늘립니다
  • 종료하면 광고와 원래 배치를 되돌립니다
  • 원하면 Windows에 로그인할 때 자동으로 켜집니다

하지 않는 일

  • 카카오톡 파일을 고치거나 덮어쓰지 않습니다
  • 카카오톡 메모리에 코드를 넣지 않습니다
  • 인터넷에 접속하거나 정보를 모으지 않습니다
  • 관리자 권한을 요구하지 않습니다

설치

설치 과정은 없습니다

  1. 내려받아 폴더에 두기

    KakaoAdHider.exe를 계속 둘 폴더에 놓습니다. 자동 실행은 이 위치를 기억합니다.

  2. 실행하기

    “Windows의 PC 보호” 창이 뜨면 추가 정보 → 실행을 누릅니다. 코드 서명이 없는 파일이라 뜨는 경고입니다.

  3. 알림 영역에서 관리하기

    작업 표시줄의 아이콘을 우클릭해 자동 실행을 켜거나 종료합니다.

알아 둘 점

이런 경우는 안 됩니다

  • Windows 전용입니다. macOS 카카오톡은 앱 구조가 달라 지원하지 않습니다.
  • 목록 아래 배너만 숨깁니다. 채팅 목록의 (광고) 메시지는 추가한 카카오톡 채널이 보낸 것이라 대상이 아닙니다.
  • 화면에서만 숨깁니다. 광고를 불러오는 통신 자체는 막지 않습니다.
  • 카카오톡을 관리자 권한으로 실행하면 일반 권한 앱이 그 창을 조작할 수 없어 동작하지 않습니다.
  • 카카오톡이 업데이트되면 창 구조가 바뀌어 광고가 다시 보일 수 있습니다. 그럴 때는 이슈로 알려 주세요.
  • 확인한 환경은 Windows 11, 카카오톡 PC 26.9.2, 100% 배율입니다.
