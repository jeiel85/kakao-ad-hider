# 카톡 광고 숨김 (kakao-ad-hider)

Windows용 카카오톡 PC 메인 창(친구·채팅 목록) 하단의 배너 광고를 숨기고, 그 자리까지 목록을 늘려 주는 작은 트레이 앱입니다.

**소개 페이지**: https://jeiel85.github.io/kakao-ad-hider/

- 실행 파일 하나(약 23KB)로 동작합니다. 대상이 .NET Framework 4.8이라 Windows 10/11에서는 따로 설치할 것이 없습니다.
- 카카오톡 파일·메모리·통신은 건드리지 않습니다. 다른 창을 보이거나 숨기고 크기를 바꾸는 Windows 공개 API만 씁니다.
- 종료하면 광고와 원래 배치가 되돌아옵니다.

> 카카오(Kakao Corp.)와 관계없는 **비공식** 도구입니다. "카카오톡"이라는 이름은 대상 앱을 가리키는 용도로만 씁니다. 사용에 따른 책임은 사용자에게 있습니다.

## 사용법

### 내려받기

[Releases](https://github.com/jeiel85/kakao-ad-hider/releases/latest)에서 `KakaoAdHider.exe`를 받아 원하는 폴더에 두고 실행하면 됩니다. 설치 과정은 없습니다.

- 코드 서명이 없는 실행 파일이라 처음 실행할 때 Windows SmartScreen이 "Windows의 PC 보호" 경고를 띄울 수 있습니다. **추가 정보 → 실행**을 누르면 됩니다.
- 받은 파일이 릴리스 노트의 SHA-256 값과 같은지 PowerShell에서 확인할 수 있습니다: `Get-FileHash .\KakaoAdHider.exe`

### 직접 빌드

[.NET SDK](https://dotnet.microsoft.com/download)가 필요합니다(.NET SDK 10에서 확인). .NET Framework 4.8 참조 어셈블리는 빌드할 때 NuGet에서 자동으로 받습니다.

```bash
dotnet build KakaoAdHider -c Release
```

빌드 결과는 `KakaoAdHider\bin\Release\net48\KakaoAdHider.exe`입니다.

### 실행

1. `KakaoAdHider.exe`를 실행하면 작업 표시줄 알림 영역(숨겨진 아이콘 `^` 안일 수 있음)에 빗금 친 `AD` 아이콘이 생깁니다.
2. 아이콘을 우클릭하면 메뉴가 열립니다.
   - **상태 표시**: `광고 숨기는 중` / `카카오톡 감지됨 (광고 영역 없음)` / `카카오톡 실행 대기 중`
   - **Windows 시작 시 자동 실행**: 현재 사용자의 `HKCU\...\CurrentVersion\Run`에 exe 경로를 등록합니다. 관리자 권한은 필요 없습니다. 등록되는 것은 exe의 **현재 위치**이므로, exe를 계속 둘 폴더로 옮긴 다음 켜세요.
   - **종료**: 숨겼던 광고를 다시 보이게 하고 목록 높이를 원래대로 돌린 뒤 끝납니다.
3. 카카오톡을 나중에 켜도 1초 안에 찾아서 적용합니다.

## 광고 제거 원리

### 1. 카카오톡 창은 어떻게 생겼나

Windows의 모든 창(버튼·목록 같은 내부 영역 포함)은 핸들(HWND)과 클래스 이름, 제목을 가진 "창"입니다. 실행 중인 카카오톡(26.9.2)의 창 계층을 조회하면 다음과 같습니다(좌표는 메인 창 기준, 높이 828px 창 예시).

```
카카오톡 메인 창          EVA_Window_Dblclk  "카카오톡"
├─ OnlineMainView_0x…     EVA_ChildWindow    본문: 좌측 메뉴 + 친구/채팅 목록   y = 31 ~ 726
├─ LockModeView_0x…       EVA_ChildWindow_Dblclk  잠금 화면(평소엔 숨김)        y = 31 ~ 726
└─ (제목 없음)             EVA_ChildWindow    광고 슬롯 — 비어 있는 자리          y = 727 ~ 827

광고 팝업                 EVA_Window_Dblclk  (제목 없음, 소유자 = 메인 창, 위치 = 광고 슬롯과 동일)
└─ … Chrome_WidgetWin_1   "MOMENT 광고"      ← 실제 광고 (Chromium 웹뷰)
```

광고는 메인 창 안에 직접 그려지지 않습니다. 카카오톡은 메인 창 바닥에 **빈 자리(슬롯)** 를 만들고, 메인 창이 **소유(owner)한 별도 팝업 창**에 웹 광고를 띄워 그 슬롯 위에 정확히 겹쳐 둡니다. 소유된 팝업이라 메인 창을 움직이면 따라오고, 항상 메인 창 위에 보입니다.

### 2. 어떻게 숨기나

필요한 조작은 세 가지입니다.

| 순서 | 대상 | 사용하는 API | 효과 |
| --- | --- | --- | --- |
| 1 | 광고 팝업 | `ShowWindowAsync(SW_HIDE)` | 광고가 화면에서 사라짐 |
| 2 | 광고 슬롯 | `ShowWindowAsync(SW_HIDE)` | 빈 자리가 그려지지 않음 |
| 3 | 본문 뷰(`OnlineMainView`, `LockModeView`) | `SetWindowPos`로 높이를 슬롯 바닥까지 | 카카오톡이 크기 변경(`WM_SIZE`)을 받아 내부 목록과 좌측 메뉴를 스스로 다시 배치 |

3번에서 목록을 직접 늘릴 필요는 없습니다. 바깥 본문 뷰의 크기만 바꾸면 카카오톡이 안쪽 목록(예: 650px → 751px)과 좌측 하단 아이콘 위치를 알아서 맞춥니다.

조작은 모두 비동기(`ShowWindowAsync`, `SWP_ASYNCWINDOWPOS`)로 요청합니다. 카카오톡이 잠시 응답하지 않아도 이 앱이 함께 멈추지 않습니다.

> 화면에서만 숨기는 방식입니다. 광고 웹뷰는 숨겨진 상태로 그대로 있으므로 광고 불러오기(네트워크 요청)까지 막지는 않습니다.

### 3. 왜 계속 감시해야 하나

한 번 숨겨도 카카오톡은 **창 크기가 바뀔 때마다 본문을 다시 슬롯 위까지 줄입니다**(실측: 창을 늘리면 본문이 726px에서 멈추고 아래가 빈칸으로 남음). 광고가 바뀔 때 팝업이 다시 표시될 수도 있습니다. 그래서 상주하면서 다시 적용합니다.

- **즉시 반응**: `SetWinEventHook`으로 카카오톡 프로세스의 `EVENT_OBJECT_SHOW`(창 표시)와 `EVENT_OBJECT_LOCATIONCHANGE`(위치·크기 변경)를 구독합니다. 재배치 한 번에 자식 창 수십 개의 이벤트가 몰려오므로 한 번의 적용으로 묶습니다. 실측으로 창 크기 변경 후 약 40ms, 광고 팝업 재표시는 측정 첫 시점(1ms) 전에 다시 처리됐습니다.
- **보완 스캔**: 1초마다 카카오톡 프로세스를 찾아 새로 켜졌거나 재시작된 카카오톡에 훅을 걸고, 혹시 놓친 변경도 바로잡습니다.

### 4. 광고 창을 어떻게 정확히 알아보나

카카오톡은 메뉴·이모티콘 선택창 같은 팝업도 같은 클래스(`EVA_Window_Dblclk`)의 제목 없는 창으로 만듭니다. 클래스 이름만으로 고르면 이런 창까지 숨길 수 있으므로 **위치 관계까지** 맞는 창만 건드립니다.

- **프로세스**: 이름이 `KakaoTalk`
- **메인 창**: 클래스 `EVA_Window_Dblclk`이고, 자식 중에 제목이 `OnlineMainView_`로 시작하는 창이 있음
- **광고 슬롯**: 메인 창의 직계 자식, 클래스 `EVA_ChildWindow`, 제목 없음. 메인 창 바닥에 붙어 있고 본문 폭 전체를 차지하며 높이가 창의 절반 이하
- **광고 팝업**: 소유자가 메인 창, 클래스 `EVA_Window_Dblclk`, 제목 없음, 화면 좌표가 슬롯과 일치(±2px)

하나라도 맞지 않으면 **아무것도 하지 않습니다**. 카카오톡 업데이트로 구조가 바뀌면 광고가 다시 보일 뿐, 카카오톡 화면이 깨지지는 않습니다.

### 5. 화면 배율(DPI) 처리

카카오톡 메인 창은 System DPI 인식 모드이고 광고 웹뷰는 Per-Monitor 모드입니다. 125%, 150% 같은 배율에서는 다른 모드의 앱이 읽는 좌표가 환산되므로, 읽고 쓸 때 반올림 오차가 생기면 크기가 1px씩 흔들릴 수 있습니다. 그래서 좌표를 다루는 동안 `SetThreadDpiAwarenessContext`로 이 앱의 스레드를 카카오톡 메인 창과 같은 모드로 맞춥니다.

### 6. 종료 시 복원

숨긴 창 목록과, 처음 봤을 때의 본문–슬롯 간격(현재 버전은 1px)을 기억합니다. 종료하면 본문 높이를 원래대로 줄이고 **이 앱이 숨긴 창만** 다시 표시합니다. 창 핸들 값은 창이 사라지면 다른 창에 재사용될 수 있습니다. 그래서 핸들과 함께 프로세스 ID와 클래스 이름이 그대로인지 확인하고, 사라진 창은 1초마다 목록에서 지웁니다.

## 한계

- **Windows 전용**입니다. 최근 논란이 된 macOS 카카오톡의 광고는 앱 구조와 OS의 창 제어 방식이 달라 이 방식으로 다룰 수 없고, 별도 구현이 필요합니다.
- **메인 창 하단 배너만** 대상입니다. 채팅 목록에 보이는 `(광고)` 메시지는 친구 추가한 카카오톡 채널이 보낸 메시지라 이 앱의 대상이 아닙니다(채널 차단이나 알림 끄기로 정리하세요). 더보기 탭 등 다른 위치의 광고는 확인하지 않았습니다.
- 카카오톡을 **관리자 권한으로 실행**하면 일반 권한 앱은 그 창을 조작할 수 없습니다(Windows UIPI). 이때는 아무 동작도 하지 않습니다.
- 카카오톡을 처음 켤 때는 광고가 최대 1초 정도 보였다가 사라질 수 있습니다.
- 카카오톡 창 구조에 기대는 방식이라, 업데이트 후 동작하지 않으면 창 구조를 다시 확인해 4번 조건을 고쳐야 합니다.

## 확인 환경

- 2026-11-04, Windows 11 Pro, 카카오톡 PC 26.9.2.5342, 100% 배율
- 확인한 것: 광고 팝업·슬롯 숨김과 본문 확장, 친구·채팅 탭 화면, 창 크기 변경 후 재적용, 광고 팝업이 다시 표시될 때 재숨김, 종료 로직의 원래 배치 복원
- 확인하지 않은 것: 125% 이상 배율, 다중 모니터, 잠금 모드 화면, 자동 실행 등록 후 재부팅
